チュートリアルについて

チュートリアルは第4章まで用意されており、基本的に案内に沿って進めれば大きくつまずくことはありません。チュートリアル終了時点で女王アリはレベル8前後まで上がっています。

最優先は女王アリのレベル上げ

The Ants は育成ゲームとしての側面が強く、女王アリのレベルを最優先で上げるのがセオリーとされています。「アリ塚レベル＝女王レベル」であり、ほとんどの建物は女王レベルを超えてアップグレードできません（ストアで購入した建物も例外ではありません）。目安としてレベル25まで上げられると、その後の巣の運営がかなり楽になります。

出典: simplegameguide.com: Queen Level Upgrade Requirements

女王アリレベル8で自動的にシールドが切れる点は特に重要です。シールド期間中に資源を防衛できる体制（アライアンス加入・資源の使い切り等）を整えておくのがおすすめです。

習性（コロニー特性）システム

女王アリLv7で選択できるようになる「習性」は、栽培・略奪・牧畜の3系統から選ぶコロニー特性です。それぞれ専属建築と、明確な利点3つ・欠点3つを持ちます（現在は無料で変更可能）。

系統 専属建築 利点 欠点
栽培 資源加工地 資源保護（略奪されにくい）／採取スピード+50%／兵隊アリ荷重+100%（採取時） 侵入時の攻撃力-30%／侵入時の防御力-30%／行軍スピード-30%
略奪 戦利品貯蔵庫 侵入時の兵隊アリ荷重+150%／死亡数の40%を負傷に変換／傷兵治療スピード+100% 植物・肉・湿土・砂の産出-30%／甘露産出-30%／採取時の兵隊アリ荷重-50%
牧畜 資源輸送通路 甘露産出+50%／兵隊アリ食物消耗-30%／旅虫生息地の商品値段-5% 侵入される時、略奪される資源量+100%／傷兵治療スピード-50%（3つ目の欠点は未確認）
出典: 自分のアカウントの習性選択画面（2026-07-19実測、栽培・略奪は当日、牧畜は2026-07-26追加確認）

リセマラについて

リセマラの必要性は低いとされています。理由は次の2点です。

  • リセマラ自体の難易度が高い（手順が煩雑）
  • 通常プレイを進めるだけでも優秀な蟻を入手しやすい

アライアンス（ギルド）への加入

アライアンスに加入すると巣の発展速度が明確に上がるため、序盤から加入しておくのがおすすめです。詳しくは アライアンスとPvP を参照してください。

無課金プレイについて

ログインボーナスやデイリータスクが充実しているため、無課金でも十分に強くなれます。毎日のタスク消化を欠かさないことが上達の近道です。

序盤で避けたいこと

  • 資源を「保護レベル」以上に貯め込みすぎて掠奪の標的になる
  • 防衛体制を整えないままシールドが切れてしまう
  • 定期イベントに参加しない（デイリータスク・アライアンス遠征など、コツコツ系の報酬を取りこぼす）
