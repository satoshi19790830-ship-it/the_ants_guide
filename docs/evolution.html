進化（研究）

進化は、蟻塚のほとんどの数値に効く土台です。他のどの育成システムより先にあり、伸ばした分がそのまま全部に乗ります。

どれくらい効くかは、自分のアカウントの内訳画面で確かめられます。

戦闘スピード：952 の内訳 — 進化隕石140 + 進化470 + 中立生物140 + 細胞30 + 遺伝子50 + 細菌50 + 真菌50 + 兵種改造2 + VIP20

ダメージ増幅：66.00% の内訳 — 進化 20.00% + 中立生物 5.00% + 建築 41.00%

戦闘スピードは6割以上が進化由来でした。他のシステムが数十ずつしか積めていないのに対して、進化だけ桁が違います。（ダメージ計算と行動順 の実測より）

「進化菌の群れ」と「異変菌の群れ」は別の建物

名前が似ていて紛らわしいので先に整理します。

建物 何をするところか
進化菌の群れ このページの主題。進化（研究）を進める
異変菌の群れ 細菌・遺伝子・細胞・真菌を装備するところ（育成システム早見）

なお細菌のコロニー解放には進化菌の群れLv5が必要で、両者は無関係ではありません。

進化菌の群れ

公式ヘルプの説明はごく短く、「色々な進化を研究して対応するステータスバフを増やす建物」「LVUPすると研究スピードが上がる」とだけ書かれています。

以下のレベルごとの数値はコミュニティの情報で、公式の記述ではありません。

  • 研究スピードは Lv4で+20%、Lv9で+45%、Lv14で+75%、Lv20で+100% と段階的に上がります。この手前で止めず、区切りまで一気に上げるのが効率的です
  • Lv8以上が「戦域開発」の進化を開くための条件
  • Lv25がT9解放の進化の前提。結局は最大まで上げることになります

研究には菌類を大量に使い、進化菌の群れ自体のLVUPには湿土を使います。進化が止まる原因はほぼ菌類切れなので、ハキリアリと自生菌の群れを早めに伸ばしておくと詰まりません。

進化の分類

進化画面はいくつかのツリーに分かれています。おおむね次の系統です。

系統 何が伸びるか
急速生産 資源の産出量、採集速度
蟻塚発展 建設速度、研究速度、コロニーの各種上限
基礎戦闘 兵隊アリの攻撃・防御・生命力、中立生物への攻撃
行軍隊列 兵種ごとのステータス、行軍スピード、負傷の軽減
戦域開発 戦域戦でのpt獲得効率と報酬（進化菌の群れLv8以上で解放）

序盤は資源系、中盤は建設・研究速度、終盤は戦闘系へ重心を移すのが一般的な進め方です。

部隊の強さに効く進化

ここは日本語コミュニティの解説にもとづきます。公式の記述ではありません。

共同作戦 — 特化アリを置ける列が増える

部隊の強さが一段変わる進化です。段階を進めるごとに、特化アリを配置できる列が増えていきます。

段階 開くもの
初級共同作戦 前列に特化アリを配置できる
中級共同作戦 中列に配置できる。快速行軍・快速回復も付く
高級共同作戦 後列に配置できる

特化アリが増えると、その支配力スキルで連れて行ける兵隊アリの数そのものが増えます。ザ・アンツ攻略Wikiでは、初級で兵力が27,500から108,350へ、高級まで進めると30万を超える例が挙げられています。

攻撃力や防御力の%を数個積むより、ここを開けるほうが効きます。

異変 — 低いティアの兵隊アリを引き上げる

  • 異変Ⅰ — T1〜T3のアリを最高ティアへ強化できるようになる
  • 異変Ⅱ — T4〜T6をT7まで強化できるようになる

古い兵が無駄にならなくなるので、兵の作り直しにかかる時間を大きく削れます。

基礎戦闘

兵隊アリの素の攻撃・防御・生命力です。中立生物狩りに効く枠もあり、解説動画では中立生物Lv11〜15に対して最大+40%の攻撃が付く「高級攻撃」が、序盤にもっとも重要だと説明されています。

行軍隊列

兵種ごとのステータスと行軍スピードです。解説動画では、キャリヤーアリの攻撃力が1つの研究で+8%、その系統を上げ切ると合計+35%（1.35倍）になる例が示されています。ここは自分が特化させている兵種に寄せるのが定石です。

負傷を減らす研究も入っています。兵が死なないこと自体が戦力なので、地味ですが効きます。

優先順位の考え方

  1. 序盤 — 資源系（特に菌類の産出）と採集速度。ここが細いと後の全部が止まります
  2. 中盤 — 建設速度・研究速度。進化菌の群れのLVUP自体を優先するのもここ
  3. 終盤 — 共同作戦・基礎戦闘・行軍隊列。対人戦を見据えるなら、1軍に使う兵種へ寄せる

戦域戦が解放されたら、戦域開発が最優先という指摘もあります。pt獲得の効率と報酬に直接効くためです。

アライアンス進化

個人の進化とは別に、アライアンス単位の進化があります。メンバーが資源をドネーションして進め、アライアンス全体にバフが乗ります。

このアライアンス総進化値は、戦域召集を起こすための条件のひとつ（1200以上）にもなっています。個人の進化と違い、自分だけでは伸ばせません。

詳細は公式ヘルプセンターの「アライアンス進化とドネーション」にあります。

「進化」と名の付く別のシステム

紛らわしいので、区別を書いておきます。このページの進化（研究）とは別物です。

  • 進化増幅（特化アリの出陣） — レア特化アリを出陣させてステータスを得る仕組み。育成システム早見
  • 征服者進化 — 6つの進化枠を育てて進化スキルを得る仕組み。同じく育成システム早見にあります
  • アライアンス進化 — 上記のアライアンス単位のもの
