Welcome to The Ants Guide

Last updated: 2026-07-19
On this page
  • Contents
  • About this site

An unofficial, community-run guide site for The Ants: Underground Kingdom.

This site has two goals:

  1. Aggregate guide content from strategy wikis, Reddit, and forums around the world
  2. Run a community project to verify the (undocumented) damage formula using real combat data submitted by players

Contents

  • Beginner Guide — Tutorial tips and queen leveling priority
  • Ant Types & Stats — Soldier ant and special ant categories and how to read stats
  • Alliance & PvP — Why joining an alliance matters, PvP basics
  • Ant & Neutral Creature Compendium — Verbatim skill data from real account screenshots (work in progress)
  • Verifying the Damage Formula — What's known so far, and the data-driven verification project
  • Contribute Your Data — Your combat logs help make this guide more accurate

About this site

  • This is an unofficial fan site, run by a hobbyist. It is not affiliated with the developer/publisher of The Ants.
  • I don't repost images from social media; I link to the original source instead.
  • Found an error? Please let us know.
