The Ants × 大怪獣ガメラ のコラボは 2026年8月31日 に開始しました。守護怪獣ガメラとアリの探検隊が世界を越えて冒険する、というのが公式が掲げたテーマです。

このページは、公式が発表した内容を日付順にまとめた記録です。未確認の項目は「未確認」と書いています。ゲーム内で確認でき次第、追記していきます。

開催期間

内容 期間
コラボ本体の開始 2026年8月31日
未知の大陸探索（Explore the Mysterious Continent） 2026年8月31日 〜 9月6日
フォーラム上の参加企画 〜 2026年9月3日 23:59:59 (UTC)

コラボ全体の終了日は、公式の告知からは確認できませんでした（未確認）。

追加されたもの

公式の案内で報酬として名前が挙がっていたのは次の3つです。

  • 選択式 特化アリ
  • コラボ限定 昆虫スキン
  • 選択式 精巧なレア特化アリのかけらチェスト

コラボ限定の特化アリが新規に実装されたのか、既存アリから選ぶ形なのかは、公式告知の文面からは判別できませんでした（未確認）。ガメラ本体がゲーム内でどう登場するか（中立生物として出るのか、演出のみか）も同様に未確認です。

未知の大陸探索

コラボの中心となる遊び方です。

  • 未知の大陸のマスを掘って、埋まっている報酬を掘り当てる
  • 一部に光るマスがあり、掘ると追加の出来事が起きることがある
  • 掘り進める中で石板などのアイテムが手に入る

公式フォーラムのコメントでは、石板を3〜5個見つけたという報告や、掘っている最中に猛獣と遭遇したという報告がありました。

開催までの前振り（ストーリー）

コラボは唐突に始まったわけではなく、8月中旬から公式フォーラムで断続的にストーリーが投下されていました。並べると、何が起きていたのかが分かります。

日付 投稿 内容
8月17日 Unknown Event #2: A Rift in Space 空間の裂け目が現れる
8月17日 Unknown Event #3: The Exploration Team 探検隊が結成される
8月20日 Unknown Event #4: A Mysterious Power 謎の力が観測される
8月23日 Unknown Event #5: The Slumbering Ancient Tree 眠っていた古木が目覚め、何かが呼び覚まされる
8月26日 The Truth Revealed: The Guardian Monster Awakens 守護怪獣の正体がガメラだと明かされる
8月28日 The Ants × Gamera｜開始3日前 カウントダウン
8月31日 コラボ開始 未知の大陸探索がスタート

「空間の裂け目 → 探検隊 → 謎の力 → 古木の目覚め → 守護怪獣の正体」という順で引っ張ってから、正体をガメラだと明かす構成でした。なお8月17日〜26日の投稿はフォーラム上の参加企画（コメントにゲームIDを書くと抽選で報酬）を兼ねており、ゲーム内のイベントではありません。

まだ確認できていないこと

正直に書いておくと、このコラボについては分かっていないことが多く残っています。

  • コラボ全体の終了日
  • コラボ限定の特化アリが新規実装なのか、既存アリの選択式なのか
  • ガメラがゲーム内でどう登場するか（中立生物・演出・スキンのいずれか）
  • 昆虫スキンの具体的な見た目と入手条件

公式の日本語アップデート告知（【8月31日】アップデートのお知らせ）は確認しましたが、この告知にコラボの記載はありませんでした。内容は進化・地下洞窟・先駆者まわりの最適化とバグ修正で、コラボはアップデート告知とは別枠で案内されているようです。ゲーム内で確認でき次第このページを埋めます。分かる方がいたら教えてください。
