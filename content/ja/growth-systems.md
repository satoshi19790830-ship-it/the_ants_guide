このゲームは、**同じステータスに対して多くのシステムが少しずつ加算していく**構造になっています。自分のアカウントの戦闘詳細画面で「ダメージ増幅：66.00%」の内訳を開くと、進化20.00% + 中立生物5.00% + 建築41.00% と表示されました（[ダメージ計算を検証する](damage-calculation.html) の発見4）。つまりどれか1つを極めるより、**乗るものを漏らさないこと**が効きます。

このページは、そのために「何がどこに効くのか」を一覧にしたものです。

## 異変菌の群れ（細菌・遺伝子・細胞・真菌）

4つとも「異変菌の群れ」を建てると開く、兵隊アリのステータスを積むシステムです。**同じ形の設計**になっているので、まとめて理解できます。

### 共通の作り

- 各パーツには**2星〜10星の9段階**（細胞のみ最大7星）
- 強化でレベルを上げ、星UPで上限を上げ、突破でさらに伸ばす
- 同じ名前のパーツは複数持てますが、**同じ枠に同名を同時アンロックはできません**
- 強化済みのパーツを素材にすると、そのパーツの全経験値が返ってきます（無駄になりません）

### 何が上がるか

**細菌**（枠は3つ×コロニー、コロニーは最大4つ）

| 細菌 | 効果 |
|---|---|
| 球菌 | ガーディアン攻撃／シューター防御／キャリヤー生命 |
| 桿菌 | シューター攻撃／… |
| 螺旋菌 | （同様の三すくみ） |

細菌コロニーの解放は、進化菌の群れLv5を前提に**女王Lv17で1つ目、Lv18で2つ目、Lv19で3つ目、Lv20で4つ目**です。

**遺伝子**（兵隊アリの4部位＝状顎・触角・甲殻・腹部に各3つ装備）

| 遺伝子 | 効果 |
|---|---|
| 痛撃遺伝子 | ガーディアン攻撃／シューター防御／キャリヤー生命 |
| 猛毒遺伝子 | シューター攻撃／キャリヤー防御／ガーディアン生命 |
| 甲冑遺伝子 | キャリヤー攻撃／ガーディアン防御／シューター生命 |

強化には肉・砂・水を、星UPにはDNAを使います。

**細胞**（6種類、最大7星）

| 細胞 | 効果 |
|---|---|
| 状顎細胞 | ガーディアン攻撃／シューター防御／キャリヤー生命 |
| 肢体細胞 | ガーディアン攻撃／キャリヤー防御／シューター生命 |
| 毒腺細胞 | シューター攻撃／ガーディアン防御／キャリヤー生命 |
| 触角細胞 | シューター攻撃／キャリヤー防御／ガーディアン生命 |
| 甲殻細胞 | ガーディアン防御／シューター生命／キャリヤー攻撃 |
| 腹部細胞 | ガーディアン生命／シューター防御／キャリヤー攻撃 |

強化には細胞液と甘露を使います。

**真菌**（4つの真菌コロニー：糸状・藻類・卵形・嚢胞）

真菌コロニー自体は**全兵隊アリの攻撃・防御・生命力**を上げます。中に入れる真菌は三すくみ型ですが、各コロニーの「核皿真菌」だけは例外で、**特化アリスキル攻撃力・スキル防御力**を上げます。特化アリのスキル火力に直接効くのはここです。

## 兵種改造

3兵種それぞれに、**ノーマル枠5つ（うち3つが兵種改造枠、2つが通用改造枠）とレア枠2つ**があります。

- 兵種改造枠とレア枠は**兵種改造池のレベル**で解放
- 通用改造枠は、その兵種の**改造協同**が指定ランクに達すると解放
- 部品は「兵種改造部品（対応兵種の枠のみ）」「全兵種改造部品（全兵種枠のみ）」「通用改造部品（どの通用枠にも）」に分かれます
- 強化には資源・本体・改造培地が必要。部品は**改造宝箱**から出て、宝箱は勇気の試練やイベント、パックで手に入ります

2026年8月3日の更新で育成資源のコストが下がり、**すでに育てていた分は差額が返還**されました。

## 働きアリ宝物

働きアリ隊列は宝物システムの解放後、**建設隊列と探索隊列に分かれ、同じ隊列で建設と探索を同時に行えます**。探索で宝物欠片を集め、アンロックするとバフが付きます。

- 品質は青 < 紫 < 橙。高いほどバフが強い
- 紫・橙は、探索隊列が一定レベルに達してから出るようになります
- 「アイランド宝物」は、洞窟宝物の**神秘化石がLv.15**に達してから解放
- 探索で得られる紫品質材料「宝物粘土」には**週180個の上限**があります

## 勲章システム

女王アリ**Lv19**で解放。タスクを達成すると勲章が付き、追加ステータスが得られます。

- 同じ種類の勲章の追加ステータスは**積み重なりません**。今アンロックしている最高値だけが乗ります
- **装備しなくても効果があります**（表示は最大3枚まで）
- 特化アリ対決を除く全ての戦闘で有効

## VIPシステム

VIPレベルは**15段階**。デイリーログインで無料のVIPポイントがもらえ、ダイヤでも購入できます。ログインでもらえるポイントは日数とともに増えますが、**1日欠席してもリセットされません**。

VIPショップは**毎週土曜〜日曜**にイベントとして開催され、指定資源とダイヤでアイテムを買えます。VIPレベルを上げるほど買えるアイテムが増えます。

## 着せ替え（星UP）

蟻塚・隊列・チャットバブル・フォトフレームの4種類があり、蟻塚と隊列には**星UP（0〜最大星10）**があります。

- 星UPのたびに新しいステータスバフが開きます
- **着せ替え自体のバフと、星UPのバフは別々に計算され、同時に乗ります**
- 期間限定着せ替えは星UPのExpにならず、バフも期限内だけです。しかも**アンロックした時点から有効時間が減り始めます**（使わなくても減ります）

## 中立生物まわりの育成

中立生物には、本体の育成とは別に**化石・宝石・宝石タレント**、**ランクアップタレントと突破**、**仲間**という層があります。

**化石**は6枠を3グループに分け、各グループが**前列・中列・後列**にバフを出します。化石1つにつき宝石を3つはめられ、宝石も同じ列に対応します。

| 化石 | 効果 |
|---|---|
| 毒腺昆虫の化石 | 前列の攻撃力 |
| 甲殻昆虫の化石 | 前列の防御力 |
| 鱗翅昆虫の化石 | 中列の攻撃力 |
| 挙腹昆虫の化石 | 中列の防御力 |
| ハンター昆虫の化石 | 後列の攻撃力 |
| 巨大ハサミ昆虫の化石 | 後列の防御力 |

宝石は硬甲エメラルド（前列）、強顎サファイア（中列）、鋭爪トパーズ（後列）で、それぞれ攻撃・防御・生命の3つに効きます。**化石も宝石も、一度装備すると取り外し・交換ができません**（強化はできます）。

化石は女王**Lv16**＋サーバー開設から一定日数で解放され、いずれかの化石がレア品質に達すると宝石システムが開きます。宝石を1回強化するごとにタレントptが1つ入ります。

**仲間絆**は紫品質以上の仲間で組み、構成する仲間が全て5星になると解放、全て8星で第二段階に進みます。現在は次の3つです。

| 絆 | 構成 |
|---|---|
| ゴールドウィング | ゴマダラジンガサハムシ＋イカルスヒメシジミ |
| 花びらの宴 | モンシロチョウ＋金ビシクラズ |
| 蝶々のダンス | アオスワロウテイル＋オナシアゲハ |

## 特化アリの育成

覚醒については [蟻の種類とステータス](ant-types.html) にまとめています。それ以外の層は次の通りです。

- **進化増幅（特化アリの出陣）** — 出陣できるのは**レア特化アリのみ**。世代が高いほど増幅が大きくなります。提供されるステータスは**出陣した数と世代だけで決まり**、どの進化セットに入れても差はありません
- **特化アリ出陣** — 各特化アリ進化に6つのスロットがあり、**同一シーズンのグループ単位**でしか出陣できません（個別不可）。効果は2匹・4匹・6匹と段階的に増えます。同じシーズンの所持が2匹未満だと出陣できません
- **スキル突破** — S5シーズン以降の特化アリは、**スキル1**を突破できます。本体の残骸を1つ消費し、突破後のステータスはスキル1のレベルに影響されず固定。ロールバックは無料・クールダウンなしで、待機状態のときに行えます
- **征服者進化** — 6つの進化枠を育て、全枠が最高レベルに達すると突破できます。品質枠は白→緑→青→紫→橙→赤と変化。6枠の突破回数が揃うと**進化スキル**を獲得し、1隊列に1つ装着できます
