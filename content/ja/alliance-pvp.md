## アライアンスへの加入

アライアンスに加入すると、建設時間短縮の支援・資源援助・専用ショップ・デイリータスク報酬などにアクセスできるようになり、巣の発展速度が明確に上がります。序盤のうちから加入しておくのがおすすめです。

### アライアンス遠征

2つのアライアンスが資源ptを競う対戦イベントです。公式ヘルプによる進行は次の通りです。

| 曜日 | 内容 |
|---|---|
| 水曜 | 申込（R4・R5が代表で申し込み、時間帯も選ぶ） |
| 木曜 | マッチング（アクティブメンバーの戦闘力の合計と時間帯が近い相手と組まれる） |
| 金曜 | 試合。**準備10分＋本戦1時間の計1時間10分** |

**得点源**

| 対象 | pt |
|---|---|
| 天然輸送通路（中立建築） | 占拠で5,000資源pt |
| お化け蒟蒻（中立建築） | 占拠で6,500資源pt。**占拠中は60秒ごとに25,000資源pt** |
| 竜舌蘭（初級・中級・高級） | 1回の採取pt＝採取効率×兵隊アリの荷重 |

**押さえておくこと**

- 天然輸送通路の周りが**安全エリア**。安全エリア内の蟻塚からしか採取隊列を出せず、その代わり安全エリア内は攻撃も受けません
- **兵隊アリは死亡しません。** 軽傷・重傷で済み、再生菌で治療でき、その治療に自分の資源は減りません。イベント後は元の状態に戻ります
- **スタミナを消費しません。** 行軍加速アイテムは使えません
- 戦場に入ると通常マップの蟻塚には自動で保護が付きます
- 準備時間中は出入り自由ですが、**開始後に出たら再入場できません**
- アイテムによる一時的な攻防バフ・蟻塚保護・偵察対策は戦場では無効です
- 戦場内の移転は移転値を消費します（自陣の安全エリア内は30、それ以外は200。1秒1点回復、上限200）

勝敗は資源ptで決まり、個人ptが個人報酬に反映されます。勝利・敗北の報酬には生命エッセンスが含まれますが、**試合に参加しなかったメンバーには配られません**。

## 戦闘の基本ルール（公式ヘルプより）

攻略の前提になる部分が公式に明記されているので、まずここを押さえておくと戦績の読み方が変わります。

**陣形**

- 対戦中は**両者3列ずつ、合計6列**（前列・中列・後列）
- **通常攻撃は、距離が最も近い目標にしか当たりません**
- 戦闘スキルの対象は、スキルの有効距離と対象指定で決まります

**侵入する側**

- 派遣できるのは**行軍隊列1つだけ**
- **守備側の隊列を全部撃破しないと勝てません**
- 成功すると相手の蟻塚耐久値にダメージを与え、資源を奪えます。甘露を奪えるのは略奪習性の隊列だけです

**守備する側**

- 前提として、**「蟻塚出口」を建てていないと行軍隊列は守衛戦闘に参加できません**。その場合は未編成の兵隊アリだけが戦うことになります
- 逆に、行軍隊列を1つも設置していなければ、蟻塚内の未編成の兵に損失は出ません（そのまま侵入成功になります）
- 資源を略奪できるのは、**侵入成功1回につき1回だけ**です

- **最大4部隊**が参戦し、順番は蟻塚出口の「駐屯」で設定した順です
- **どれか1部隊が勝てば守備成功**
- 編成に入っていない兵隊アリは戦闘に参加しませんが、守備失敗時には一部が負傷します

**蟻塚耐久値**

- 侵入されると耐久値が減り、破損状態になります。**破損状態は時間が経つほど耐久値が減り続けます**
- 満タンでなければ時間経過で自動回復し、ダイヤで即修理もできます
- **0になると自動的にランダム移転**し、新しい座標で500まで回復します
- 与えるダメージ量は侵入部隊の**破壊値**と同じで、破壊値は特化アリと兵隊アリ数で決まります

## 対人戦（PvP）

### 掠奪（Plunder）

シールドのない敵拠点を襲撃して資源を奪う要素です。事前にスカウト（偵察）で相手の戦力を確認してから仕掛けるのが基本です。女王アリレベル8になると新規プレイヤー向けのシールドが自動解除され、以後は他プレイヤーからの侵略対象になります。「レイダー」クラスは掠奪特化で、専用施設解放後は追加の行軍部隊が付与され、侵略時の兵蟻積載量が+150%になります。

実測値の一例として、掠奪2時間で肉・植物・湿土3,500万〜5,000万、砂500万を獲得できたという中国コミュニティの報告があります。

略奪できる量は、**隊列の荷重と相手の資源保護状況**で決まります。相手が保護上限内に資源を収めていれば、勝っても取れるものはほとんどありません。

> ここについて、プレイヤー「ありをそだてるあきとくん」氏の解説動画<a href="https://www.youtube.com/watch?v=ILBTZtsrtw0">「これは知らないと強くなれない知識まとめ」</a>（2021年11月23日公開）では、**取れる量は相手の資源量ではなく自分の部隊の荷重で決まる**と説明されています。相手にいくら資源があっても、荷重を超えては運べないという意味です。加えて、**蟻塚レベルが6以上離れている相手からは30%しか取れない**とも述べられています。**公式の記述ではなく、公開から年数が経っています。**

**偵察**を先に打つと、相手の座標・略奪できる資源・蟻塚耐久値・兵隊アリ数が分かります。偵察アリのレベルが高いほど詳しくなります。ただし相手が「偵察対策」アイテムを使っていると情報は取れず、「蟻塚保護」を使っている相手には攻撃も偵察もできません。

### 最強戦域戦（Strongest Warzone）

戦域（サーバー）同士が日替わりタスクの得点で competing するイベントです。公式ヘルプでは**予選 → 練習試合 → クラス戦**という段階構成になっています。

| 段階 | 期間 | 7日目のテーマ |
|---|---|---|
| 予選 | 1ラウンド7日間 | マーモット制圧 |
| 練習試合 | 2ラウンド（各7日間） | 1ラウンド目はマーモット制圧、2ラウンド目は戦域征戦 |
| クラス戦 | 練習試合と同じ内容 | 同上。ただし毎週の勝敗が戦域のクラスPtに反映される |

各ラウンドとも**5日目まではシステムが決めたテーマ**で、**6日目は自分でテーマを選べます**。一度クラス戦に入ると、以降の最強戦域戦はすべてクラス戦になります。クラスが高い戦域ほど報酬が良くなります。

日々のタスクを達成すると個人ptと同数の戦域ptが入り、アライアンス所属者にはアライアンスptも入ります。その日のイベント終了時点でptが高い戦域が勝ち、勝利ptを1つ得ます。

> 一部の日本語攻略情報で「猛毒菌の群れ」「真菌大戦」といった名称のイベントが言及されていますが、今回の調査では公式イベント名との対応関係を確認しきれませんでした。詳細が分かり次第このページに反映します。

## 異変荒野（Mutated Barren）シーズン

サーバーをまたぐ大型のシーズン制PvPコンテンツです。2026年9月5日に大きな仕様変更が発表され、
9月7日以降に受付が始まるイベントから適用されています。主な変更点は次の通りです。

- 宣戦布告できるのは保護期間前の4時間枠のみ。戦闘時間が終わると進行中の布告は自動でキャンセルされる
- 宣戦の準備時間が10分に短縮
- 1アライアンスが宣戦できる拠点は1つ、1キャンプが狙える敵陣営の拠点も1つまで
- 拠点は内部に部隊を駐留させても耐久が回復しなくなった
- 陣営前哨が恒久保護になり、保護範囲も拡大
- **休戦日（Truce Day）が新設**。チャンピオンポイント第2段階の開始から2週間、毎週水曜と土曜（UTC基準）は拠点攻撃と監視哨建設ができない
- 集結への自動参加が最大1分30秒以内に行われるようになった（手動参加を優先する10秒の遅延あり）。これは全シーズン共通の変更

変更前の仕様で書かれた攻略情報がまだ多く残っているので、シーズンに参加する前に
[最新情報](news.html) で現在の仕様を確認することをおすすめします。

## 蟻王争奪戦

戦域マップ中心の**豊饒の地（座標 600:600）**を占拠したアライアンスが、その戦域の蟻王を選ぶ権利を得るイベントです。準備段階 → 争奪段階 → 保護段階の3段階を繰り返します。

- **争奪段階は土曜の00:00〜23:59:59**（システム時間）。占拠の進度が最も早く100%に達したアライアンスが勝ち。誰も100%に達しなければ、終了時点で進度が最も高いアライアンスが取ります
- 豊饒の地の周りに**鉄砲瓜が4つ**あります。鉄砲瓜との戦闘では、重傷の兵が治療池の収容上限を超えない限り死亡しません（超えると死亡します）
- 豊饒の地と鉄砲瓜を別々のアライアンスが占拠していると、**鉄砲瓜が30秒ごとに豊饒の地を攻撃**します
- 争奪終了後、豊饒の地は**7日間の保護段階**に入り攻撃できなくなります

**蟻王になると**

任期中は兵隊アリ攻撃力+50%、防御力+50%、隊列行軍スピード+100%という強力なバフが付きます。加えて戦域内の任意のリーダーに**職位（バフ）や罰（デバフ）を与えられます**。

| 職位の例 | 効果 |
|---|---|
| 収穫蟻 | 全資源産出+50%／兵隊アリ肉消耗-10%／採取スピード+20% |
| 蟻皇后 | 全資源産出+30%／兵隊アリ孵化消耗-5%／採取エキストラ獲得+10% |
| 戦神蟻 | 兵隊アリ攻撃力+20%／行軍スピード+10%／生命力+10% |
| 護衛蟻 | 兵隊アリ攻撃力+20%／防御力+20% |

| 罰の例 | 効果 |
|---|---|
| ボケ蟻 | 侵入時の略奪資源量-50%／侵入後1時間は蟻塚保護を使えない |
| 臆病蟻 | 貯蔵上限-20% |
| 頓馬蟻 | 兵隊アリ行軍スピード-15% |

蟻王になる条件は、女王アリLv15以上・24時間以内にログイン・職位や罰が付いていない・「世界制覇」の試合段階や決算段階に参加していないことです。

## 定期タスクのローテーション（曜日別テーマの例）

8時間ごとに1セット、1日3周する日替わりタスクのローテーションがあり、曜日ごとにテーマが変わります。

| 曜日 | テーマ |
|---|---|
| 月 | 建築レベルアップ加速 |
| 火 | 兵隊アリ孵化 |
| 水 | 生物残骸消費（進化研究） |
| 木 | 特化アリ強化・スキル関連 |
| 金 | 兵隊アリ孵化・遺伝子関連 |
| 土 | 複合タスク |
| 日 | 中立生物の孵化・強化 |
