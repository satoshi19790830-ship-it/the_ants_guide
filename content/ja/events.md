常設・定期のイベントと対戦モードを、参加条件と要点だけ拾って並べました。アライアンス単位の大型イベント（アライアンス遠征・最強戦域戦・蟻王争奪戦）は [アライアンスとPvP](alliance-pvp.html) にあります。

## 一覧

| モード | 参加条件 | ひとことで |
|---|---|---|
| 水晶鉱坑 | 水晶鉱坑の解放 | 鉱脈を占拠して奇妙水晶を採る。レア以上は略奪もできる |
| 特化アリ対決 | 決闘坑道 | 挑戦券を使ったptランキング戦。**育成システムの多くが無効** |
| 勇気の試練 | 女王Lv12以上 | アライアンスでセンザンコウを殴り、ダメージがptになる（3日間） |
| トビトカゲバトル | 女王Lv14以上 | 毎日1匹のニジトカゲを単独で殴る（6日間） |
| アライアンス試練 | アライアンス所属 | エリマキトカゲに挑む。**兵は軽傷のみで死なない** |
| 遷移の旅 | 戦域遷移アイテム | 他の戦域へ引っ越す |
| 戦域召集 | 盟主・条件あり | 他戦域の無所属プレイヤーを自アライアンスに招く |
| シーズン孵化 | シーズン試合段階 | シーズン異変卵で特化アリを引く |

## 水晶鉱坑

鉱脈を隊列で占拠して**奇妙水晶**を集めます。

- 鉱脈のマークで状態が分かります。**マーク無し＝空き地**（戦闘不要）、緑＝自分、青＝アライアンスメンバー（略奪不可）、赤＝他人（略奪可）、紫＝自分を略奪した相手（復讐可）
- **隊列の中身は採掘速度にも総量にも影響しません。** 隊列は鉱脈を守るためだけに使います
- 鉱坑には3種類あり、採集量と速度は 水晶鉱坑 < レア水晶鉱坑 < 卓越水晶鉱坑。**水晶鉱坑は隊列1つのみ・略奪なし**、レアと卓越は最大4隊列・略奪あり
- 占拠に成功すると**3時間の保護時間**が付きます
- 略奪に成功すると相手の**採集済み奇妙水晶の50%**を得て鉱脈を奪えます。失敗すると同じ鉱脈には5分のクールダウン

**無料占領回数**は毎日UTC0時に回復します。初期は1日6回で、**女王Lv25で+2**、**増幅システムの解放で+2**。ダイヤで1日10回まで補充でき、補充は週10回まで（月曜UTC0時にリセット）。

> 補充した回数を当日使い切らないと、翌日UTC0時にリセットされて消えます。買ったらその日のうちに使い切ってください。

## 特化アリ対決（決闘坑道）

**このゲームで最も特殊なルールの対戦モード**です。クラスは無く、順位だけがあります。

- 初参加時の基礎ptは**1000**。勝てば相手との差に応じてptを得て、相手は減ります
- 挑戦券は**最大10枚所持**、**毎日5回無料**。ダイヤで買えますが、1回買うごとに必要ダイヤが増えます
- 挑戦中・挑戦されている最中は、他のプレイヤーから挑戦されません
- 戦闘履歴は**最大30件**。自分を破った相手には**1件につき1回だけ**挑戦し返せます（相手が防御成功していた場合は不可）
- **防御隊列は空にできません。** 各隊列に最低1体の特化アリが必要です。1隊列だけ相手から見えないよう非表示にできます
- 防御隊列の特化アリや中立生物を分解すると、応戦時にその枠は消えます

**ここが重要**：覚醒・勲章・征服者進化・働きアリ宝物のバフは、いずれも特化アリ対決では**無効**です（[育成システム早見](growth-systems.html) 参照）。対決で強い編成は、通常戦の強さとは別物になります。

## 勇気の試練（センザンコウ）

イベント開催から**3日間**。女王アリ**Lv12以上**が参加条件です。

- R4・R5が餌を使って**センザンコウを召喚**し、アライアンスメンバーだけが攻撃できます（単独侵入または集結）
- **1日の攻撃上限は15回**
- **センザンコウは倒せません。** ptは与えたダメージで計算されます
- 毎日ステータスが変わるので、ヒントに従って推奨兵種に隊列を組み替えるとダメージが伸びます
- 報酬は個人ptのランク／ランキングと、アライアンスptのランク／ランキングの4種類

兵種改造の**改造宝箱**がここで手に入ります。

## トビトカゲバトル（ニジトカゲ）

イベント開催から**6日間**。女王アリ**Lv14以上**、かつサーバーがシーズンを開催済みで現在シーズン中でないことが条件です。

- 毎日**10時に1匹**のニジトカゲが出現。**集結攻撃はできません**（単独のみ）
- **1日5回まで**、1回につき**スタミナ5**を消費
- 行軍時間は最大30秒に短縮されます
- ニジトカゲも倒せず、ptはダメージで決まります

**曜日で推奨兵種が変わります。**

| 曜日 | 推奨 |
|---|---|
| 月・木 | ガーディアンアリ |
| 火・金 | シューターアリ |
| 水・土 | キャリヤーアリ |

## アライアンス試練（エリマキトカゲ）

**準備段階（おとり配置、48時間）→ 攻撃可能段階 → 攻撃段階**を循環します。

- 参加できるのは、**直近46時間以内にアライアンス試練に参加していないメンバー**
- シーズンマップやアライアンス遠征の雨林マップに入った人、シーズンマップを出て46時間以内の人は参加できません
- **戦闘で兵隊アリは重傷にも死亡にもならず、軽傷だけ**。戦闘後に自動回復します
- R4・R5がおとりを野外マップに配置し、アライアンスは試練の自動開始時刻を予約できます

## 遷移の旅（戦域の引っ越し）

- 遷移できるのは**同じグループの戦域**だけ。各戦域の受け入れ上限は**300人**
- 各戦域の蟻王が、受け入れる蟻塚のレベル上限を設定できます
- 自分の戦闘力が移動先の上位に入る場合、**移動先の蟻王の承認**が必要です
- 必要な戦域遷移アイテムは蟻塚レベルで変わります

| 蟻塚Lv | 必要数 |
|---|---|
| 15〜17 | 1 |
| 18〜19 | 2 |
| 20 | 3 |
| 21 | 4 |
| 22 | 6 |
| 23 | 8 |
| 24 | 10 |
| 25 | 15 |

戦域を移るとイベントの進度がリセットされることがあります。受け取れる報酬はメールで届きます。

## 戦域召集

シーズン申込期間中、盟主が他戦域の**アライアンス未所属**のプレイヤーを自分のアライアンスへ招くイベントです。発起には条件があります。

- 直近3日のアクティブメンバーが**30人以上**
- 直近3日に**T8以上の兵隊アリを解放したメンバーが25人以上ログイン**
- アライアンス総進化値が**1200以上**

条件を満たさなくなったアライアンスの召集は、毎日UTC23:55〜翌0:05の間にシステムが取り消します。**一度発起すると撤回はできません**（条件の編集は可能）。

## シーズン孵化

シーズン試合段階が始まる週の**木曜0時（UTC）**から、特化アリの孵化画面に出ます。シーズン異変卵1個で1回引けます。

**幸運値**が肝です。1回引くごとに1pt貯まります。

| 幸運値 | もらえるもの |
|---|---|
| 100pt | 一部のシーズン特化アリからランダムで1体 |
| 300pt | **全シーズン特化アリ**からランダムで1体 |
| 600pt・800pt | シーズン孵化 幻の異変卵 |

幸運値で得た特化アリは「30回で必ずシーズン特化アリ」のカウントには影響しません。シーズン終了で幸運値は0に戻ります。

> **シーズン異変卵は持ち越せません。** シーズンが終わると未使用分は通常の特級異変卵に変わり、欠片も期限切れになって少量のダイヤにしかなりません。**必ず使い切ってください。**
